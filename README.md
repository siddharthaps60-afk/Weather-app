# 🌦️ Weather Forecasting Web Application

A modern and responsive Weather Forecasting Web Application built using **React.js**, **JavaScript**, **HTML5**, **CSS3**, and the **OpenWeatherMap API**.

---

## 🚀 Features

- 🌍 Search weather by city
- 📍 Auto-detect current location
- 🌡️ Current temperature
- 🌡️ Feels Like temperature
- ☁️ Weather condition
- 🌤️ Weather icons
- 💧 Humidity
- 🌬️ Wind Speed
- 🧭 Pressure
- 👁️ Visibility
- 🌅 Sunrise & Sunset
- 📅 5-Day Weather Forecast
- 🕒 Hourly Forecast
- 🌧️ Rain Probability
- 🌙 Dynamic Weather Background
- 🔄 Refresh Weather Button
- ❤️ Favorite Cities
- 🌡️ °C / °F Toggle
- ⏳ Animated Loading Spinner
- 📱 Responsive Design

---

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6)
- HTML5
- CSS3
- Axios
- OpenWeatherMap API
- Geolocation API

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/weather-app.git
```

Go into the project folder

```bash
cd weather-app
```

Install dependencies

```bash
npm install
```

Run the application

```bash
npm run dev
```
